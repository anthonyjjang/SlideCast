## 4. 유사 서비스 현황 (상세)

### Synthesia (가장 유사한 글로벌 서비스)

- **특징:** AI 아바타가 발표하는 영상
- **요금:** $29/월 (10분), $89/월 (무제한)
- **한계:** 한국어 아바타 품질 낮음, 슬라이드 노트 자동화 없음
- **MAU:** ~100만 명 (2024 기준)
- **시사점:** 아바타 없이 슬라이드+음성만으로도 수요 충분

### 타입캐스트 (국내 유사 서비스)

- **특징:** AI 성우 서비스, 텍스트 → 음성
- **요금:** ₩19,800/월~
- **한계:** 영상 합성 없음, PPTX 연동 없음
- **시사점:** 국내 TTS 수요 검증됨, 영상 합성 추가 시 차별화

### 클로바더빙 (Naver)

- **특징:** 네이버 TTS 기반 더빙 서비스
- **요금:** 무료~₩11,000/월
- **한계:** 슬라이드 연동 없음, 영상 출력 없음
- **시사점:** 국내 TTS 서비스 수요 검증

| **건당 합계** | **~₩30** | **~₩650** |

### 월 인프라 고정비

| 항목 | 스펙 | 월 비용 |
|------|------|--------|
| EC2 API 서버 | t3.medium | ₩45,000 |
| EC2 Worker × 2 | c5.large × 2 | ₩200,000 |

| ElastiCache Redis | t3.micro | ₩20,000 |
| S3 스토리지/전송 | 100GB 기준 | ₩8,000 |
| CloudFront | 100GB 기준 | ₩12,000 |
| **고정비 합계** | | **₩320,000/월** |

### 손익분기점 (BEP)

```
무료 플랜 사용자 원가: ₩30/건 × 3건/월 = ₩90/월 (무시 가능)
유료 플랜(₩9,900) 원가: 고정비 + 변동비
  - 변동비: 건당 ₩650 × 평균 10건 = ₩6,500/월
  - 고정비 배분: 유료 사용자 수에 따라 감소

BEP 계산:
  고정비 ₩320,000 ÷ (₩9,900 - ₩6,500) = 약 95명
  → 유료 고객 95명이면 손익분기 달성
```

## 7. 다국어 기능 — 핵심 차별화 전략

### 기능 개요

```
[한국어 PPTX 노트]
        ↓
  자동 번역 (Google/DeepL)
        ↓
┌───────┬───────┬───────┬───────┐
│  한국어│  영어  │  일본어│  중국어│
│  음성  │  음성  │  음성  │  음성  │
└───────┴───────┴───────┴───────┘
        ↓
  언어별 MP4 영상 자동 생성
```

### 지원 언어 로드맵

| 단계 | 언어 | 시기 |
|------|------|------|
| MVP | 한국어, 영어 | Phase 1 |
| v1.1 | 일본어, 중국어 | Phase 2 |
| v1.2 | 스페인어, 프랑스어, 독일어 | Phase 3 |
| v2.0 | 아랍어, 힌디어 등 | 이후 |

### 글로벌 발표 Use Case

```
시나리오: 한국 기업이 해외 투자자에게 IR 발표
  1. 한국어 PPTX 작성 (슬라이드 노트 = 한국어 스크립트)
  2. SlideNarrator 업로드
  3. 언어 선택: 영어, 일본어, 중국어
  4. 3개 언어 영상 동시 생성
  5. 각 국가 투자자에게 맞춤 영상 전달
```

## 9. 개발 로드맵 요약

```
Month 1: MVP (로컬 웹앱)
  → PPTX 파싱 + TTS + 영상 합성 + 기본 UI

Month 2: 서비스 런칭
  → 클라우드 배포 + 다국어 번역 + 베타 테스트

Month 3: 유료화
  → 결제 연동 + 회원 시스템 + 사용량 관리

Month 4~6: 성장
  → 자막, 배경음악, 전환 효과 + 마케팅 강화

Month 7~12: 확장
  → API 서비스 + 기업 연동 + 글로벌 진출
```

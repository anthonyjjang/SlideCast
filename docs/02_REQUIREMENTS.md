# 02. 기능 요구사항

---

## 1. 사용자 스토리

| ID | 역할 | 요구 | 가치 |
|----|------|------|------|
| US-01 | 발표자 | PPTX를 업로드하면 슬라이드 노트로 영상을 자동 생성 | 녹화 없이 발표 영상 완성 |
| US-02 | 발표자 | 목소리(성별/톤)를 선택 | 원하는 분위기의 나레이션 |
| US-03 | 발표자 | 특정 슬라이드만 재생성 | 수정 시 전체 재작업 불필요 |
| US-04 | 강사 | 자막이 포함된 영상 생성 | 청각 장애인 접근성, 이해도 향상 |
| US-05 | 기업 | 여러 파일을 일괄 처리 | 대량 콘텐츠 효율 생산 |
| US-06 | 사용자 | 영상 생성 진행 상황 확인 | 완료 시점 예측 가능 |
| US-07 | 사용자 | MP4 파일 다운로드 | 다른 플랫폼에 업로드 활용 |

## 3. 비기능 요구사항 (Non-Functional Requirements)

### 성능

| 항목 | 요구 수준 |
|------|---------|
| 파일 업로드 시간 | 100MB 기준 30초 이내 |
| 슬라이드 1장당 처리 시간 | 10초 이내 |
| 30장 PPTX 전체 처리 | 5분 이내 |
| API 응답 시간 | 95% 요청 1초 이내 |
| 동시 처리 작업 수 | 최소 5개 |

### 가용성 및 신뢰성

| 항목 | 요구 수준 |
|------|---------|
| 서비스 가용성 | 99% 이상 (월 7.3시간 이하 다운) |
| 영상 생성 성공률 | 95% 이상 |
| 실패 시 재시도 | 최대 3회 자동 재시도 |
| 데이터 보관 | 생성 영상 24시간 보관 후 삭제 |

### 보안

| 항목 | 요구 수준 |
|------|---------|
| 파일 전송 | HTTPS 필수 |
| 업로드 파일 바이러스 검사 | 필수 |
| 사용자 파일 격리 | UUID 기반 디렉터리 |
| 개인정보 | 최소 수집, 암호화 저장 |

### 확장성

| 항목 | 요구 수준 |
|------|---------|
| 수평 확장 | Worker 인스턴스 추가 가능 |
| 스토리지 | S3 연동으로 무제한 확장 |
| 다국어 | 언어 모듈 플러그인 구조 |

## 4. 화면 흐름 (User Flow)

```
[랜딩 페이지]
    │
    ▼
[파일 업로드]
    │
    ├─ PPTX 업로드 → [슬라이드 노트 자동 추출]
    └─ PNG + 스크립트 업로드
    │
    ▼
[스크립트 확인 & 편집]
  - 슬라이드별 스크립트 표시
  - 인라인 편집
    │
    ▼
[설정 선택]
  - 목소리 선택 (샘플 미리 듣기)
  - 화면 전환 딜레이
  - 해상도, 자막 여부
    │
    ▼
[영상 생성 시작] → [진행 상황 표시]
  ██████░░░░ 60% - 슬라이드 18/30 처리 중
    │
    ▼
[완료 화면]
  - 미리보기 (처음 30초)
  - MP4 다운로드
  - 공유 링크 복사
```

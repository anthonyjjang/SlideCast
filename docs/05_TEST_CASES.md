# 05. 테스트 케이스

---

## 1. 테스트 전략

```
단위 테스트 (Unit)        → 각 모듈 개별 기능 검증
통합 테스트 (Integration)  → 모듈 간 연동 검증
E2E 테스트               → 전체 흐름 검증
성능 테스트               → 처리 속도, 동시 처리
```

## 4. E2E 테스트

### TC-E-01. 사용자 시나리오

**시나리오 1 — 기본 영상 생성**
```
1. 브라우저에서 서비스 접속
2. PPTX 파일 드래그 앤 드롭 업로드
3. 슬라이드 노트 추출 확인 (미리보기)
4. 목소리 선택 (남성/한국어)
5. 영상 생성 시작
6. 진행 바 확인 (0% → 100%)
7. MP4 다운로드
8. 영상 재생 → 슬라이드 씽크 확인
```

**시나리오 2 — 스크립트 편집 후 생성**
```
1. PPTX 업로드
2. 슬라이드 3 스크립트 수정
3. 영상 생성
4. 슬라이드 3 음성이 수정 내용인지 확인
```

**시나리오 3 — 다국어 영상**
```
1. 한국어 PPTX 업로드
2. 언어 → 영어 선택
3. 번역 미리보기 확인
4. 영어 목소리 선택
5. 영상 생성
6. 영어 나레이션 확인
```

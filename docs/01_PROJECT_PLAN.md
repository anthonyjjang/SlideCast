# 01. 프로젝트 계획

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | SlideNarrator |
| 목표 | PPTX → AI 음성 영상 자동 변환 웹 서비스 |
| 타겟 | 기업 발표자, 강사, 콘텐츠 크리에이터 |
| MVP 목표 | 로컬 실행 가능한 웹앱 → 클라우드 배포 |
| 착수일 | 2026-05-07 |

---

## 2. 문제 정의

### 현재 발표 영상 제작의 Pain Point

1. **시간 소요** — 발표 녹화, 편집에 수 시간 필요
2. **장비 필요** — 마이크, 조용한 환경 확보 어려움
3. **수정 어려움** — 일부 수정 시 전체 재녹화 필요
4. **언어 장벽** — 외국어 발표 시 한계
5. **비용** — 전문 나레이터/성우 고용 비용

### 해결책

```
슬라이드 노트(텍스트) → AI TTS → 자동 영상 합성
수정 시 해당 슬라이드만 재생성 → 전체 재녹화 불필요
```

## 3. 목표 및 성공 지표

### MVP 성공 기준 (1개월)

| 지표 | 목표 |
|------|------|
| 영상 생성 성공률 | 95% 이상 |
| 평균 처리 시간 | 슬라이드 1장당 10초 이내 |

| 지원 언어 | 한국어, 영어 |

### 상용화 성공 기준 (3개월)

| 지표 | 목표 |
|------|------|
| 월 활성 사용자 | 500명 |
| 유료 전환율 | 10% |
| 월 매출 | ₩500만 |
| NPS | 40 이상 |

## 4. 마일스톤

```
Phase 0 — 기반 구축 (1~2주)
  ├─ 프로젝트 셋업 (FastAPI 앱 뼈대)
  ├─ PPTX 노트 추출 모듈
  ├─ TTS 연동 모듈
  └─ ffmpeg 영상 합성 모듈

Phase 1 — MVP 완성 (3~4주)
  ├─ 파일 업로드 UI
  ├─ 비동기 작업 처리 (Celery)
  ├─ 진행 상황 실시간 표시
  └─ MP4 다운로드 기능

Phase 2 — 품질 개선 (5~6주)
  ├─ 슬라이드 렌더링 품질 개선
  ├─ 목소리 선택 UI
  ├─ 슬라이드별 딜레이 조정
  └─ 자막 삽입 기능

Phase 3 — 상용화 (7~8주)
  ├─ 회원가입/로그인
  ├─ 결제 연동 (토스페이먼츠)
  ├─ 클라우드 배포 (AWS)
  └─ 모니터링 구성

Phase 4 — 영상 고도화 (9~12주)
  ├─ YouTube 패키지 자동 생성 (SRT 자막, 챕터, 썸네일)
  ├─ 다국어 자막 자동 번역 (한/영/일/중)
  ├─ 영상 내 섹션 구분 기능 ★
  │     ├─ PPTX 목차 구조 기반 섹션 자동 감지
  │     ├─ 섹션 타이틀 카드 자동 삽입 (전환 화면)
  │     ├─ 섹션별 색상/스타일 테마 선택
  │     └─ 섹션 진행 인디케이터 오버레이
  └─ YouTube Data API 자동 업로드

Phase 5 — 플랫폼 확장 (13~16주)
  ├─ API 서비스 (기업 연동)
  ├─ 배경음악 + 전환 효과 라이브러리
  ├─ AI 썸네일 자동 디자인
  └─ 글로벌 서비스 확장
```

## 5. 타임라인

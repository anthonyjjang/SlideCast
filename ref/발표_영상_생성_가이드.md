# 발표 영상 자동 생성 가이드

> 작성일: 2026-05-07
> 최종 수정: 2026-05-07 (화면 전환 딜레이 적용)
> 작업 환경: Mac Mini (macOS)
> 결과물: `발표_영상_최종.mp4` (34분 25초, Full HD 1920×1080)

---

## 1. 개요

엑셀 발표 스크립트 + PowerPoint 슬라이드 이미지 + AI 음성을 결합하여  
**슬라이드별 완벽 씽크 영상**을 자동으로 생성하는 파이프라인.

```
[엑셀 스크립트] → 슬라이드별 AI 음성 생성 (59개 MP3)
[PPT PNG 이미지] ─┤
                  └→ 슬라이드 No. 1:1 매칭 → 화면 전환 1.5초 딜레이 → [MP4 영상]
```

```

├── 부산은행 WEB대출 서비스 제안서_발표본(노트)_수정.pptx  ← 발표용 PPTX
```

## 3. 엑셀 스크립트 구조

| 열 | 컬럼명 | 용도 |
|----|--------|------|
| A | No. | 슬라이드 번호 (PNG 파일명과 1:1 매칭) |
| D | 노트 소요시간 | 참고용 발표 시간 (영상 씽크에는 미사용) |
| G | 발표 스크립트 | 원본 스크립트 |
| **H** | **수정안** | **음성 생성 우선 기준** |

> H열이 "수정 불필요"이거나 비어있으면 G열 원본 자동 사용

## 6. 영상 생성 절차

### STEP 1 — 슬라이드별 음성 생성

```bash
cd "/Users/loveauden/Library/CloudStorage/OneDrive-모빌씨앤씨/전략 사업팀 - BusanBank/제안서_발표"
python3 generate_audio_per_slide.py
```

**처리 내용:**
- 엑셀 A열 슬라이드 No. 기준으로 H열(수정안) / G열(원본) 스크립트 추출
- Microsoft Edge TTS (`ko-KR-HyunsuMultilingualNeural`) 로 슬라이드별 MP3 생성
- `slide_audio/slide_01.mp3` ~ `slide_59.mp3` 저장
- 5개씩 병렬 처리로 속도 최적화

**소요 시간:** 약 2~3분

---

### STEP 2 — 영상 합성

```bash
python3 generate_video.py
```

**처리 내용:**
- `슬라이드N.png` + `slide_N.mp3` 를 슬라이드 번호 기준 1:1 매칭
- 슬라이드 전환 후 **1.5초 무음** → 오디오 시작 (화면 먼저, 스크립트 후)
- 각 슬라이드 총 길이 = 오디오 재생 시간 + 1.5초
- ffmpeg `adelay` 필터로 오디오 딜레이 처리
- ffmpeg으로 슬라이드별 영상 세그먼트 생성 후 전체 합치기
- 해상도: 원본 720×498 → 1920×1080 업스케일 (레터박스 처리)

**소요 시간:** 약 5~10분

> 딜레이 조정: `generate_video.py` 상단의 `SLIDE_DELAY = 1.5` 값 변경 후 재실행

## 7. 씽크 방식 변경 이력

| 버전 | 방식 | 문제점 |
|------|------|--------|
| v1 | ~~D열 비율 분할~~ - 전체 오디오를 D열 소요시간 비율로 나눔 | 실제 발화 길이와 불일치 |
| v2 | ~~슬라이드별 개별 생성~~ - 슬라이드 No. 1:1 매칭, 딜레이 없음 | 화면 전환과 스크립트 동시 시작 |
| **v3** ✅ | **슬라이드별 개별 생성 + 1.5초 딜레이** - 화면 먼저, 스크립트 후 | 없음 |

### 딜레이 적용 원리

```
[슬라이드 화면 전환] → 1.5초 무음 → [스크립트 시작] → 오디오 종료 → [다음 슬라이드 전환]
```

ffmpeg `adelay` 필터 적용:
```python
SLIDE_DELAY = 1.5  # generate_video.py 상단에서 조정 가능
"-filter_complex", f"[1:a]adelay={delay_ms}|{delay_ms}[a]"
```

## 9. 특정 슬라이드만 재생성하는 방법

스크립트 수정 없이 해당 슬라이드 MP3만 삭제 후 STEP 1 재실행하면  
해당 슬라이드만 다시 생성됨 (나머지는 기존 파일 유지 불가 — 전체 재실행 필요).

특정 슬라이드 수동 생성:

```bash
edge-tts --voice ko-KR-HyunsuMultilingualNeural \
  --text "여기에 스크립트 입력" \
  --write-media slide_audio/slide_03.mp3
```

# 발표 스크립트 음성 생성 가이드

> 작성일: 2026-05-07
> 최종 수정: 2026-05-07 (슬라이드별 개별 음성 생성 방식 추가)
> 대상 파일: `발표_스크립트_시트.xlsx`
> 작업 환경: Mac Mini (macOS)

---

## 1. 개요

엑셀 발표 스크립트를 자동으로 음성 파일(MP3)로 변환하는 작업.
용도에 따라 두 가지 방식으로 운영:

| 용도 | 방식 | 스크립트 |
|------|------|---------|
| **영상 제작용** (권장) | 슬라이드별 개별 MP3 59개 생성 | `generate_audio_per_slide.py` |
| 단독 청취용 | 전체 스크립트 MP3 1개 생성 | `generate_audio_edge.py` / `generate_audio_revised.py` |

---

## 2. 엑셀 파일 구조

| 열 | 컬럼명 | 설명 |
|----|--------|------|
| A | No. | 슬라이드 번호 (PNG 파일명과 1:1 매칭) |
| B | 목차 | 목차 구분 |
| C | 슬라이드명 | 슬라이드 제목 |
| D | 노트 소요시간 | 예상 발표 시간 (참고용) |
| E | 실제 소요시간 | 실측 발표 시간 |
| F | 주요내용 (키메시지) | 핵심 메시지 |
| **G** | **발표 스크립트** | **원본 스크립트** |
| **H** | **수정안** | **음성 생성 우선 기준** |
| I | 수정 사유 | 수정 이유 |

- 총 **59개 슬라이드** (2행~60행)
- 총 **12,550자**

### 스크립트 선택 로직

```
H열 값 확인
  ├─ 내용 있고 "수정 불필요" 아님 → H열 수정안 사용
  └─ "수정 불필요" / 비어있음     → G열 원본 사용
```

## 3. TTS 방식 선택 과정

| 방식 | 한국어 품질 | 남성 목소리 | 비용 | 결과 |
|------|-----------|-----------|------|------|
| macOS `say` (Yuna) | ★★★☆☆ | ❌ | 무료 | 여성만 정상 동작 |
| macOS `say` (Eddy/Reed/Rocko) | ❌ | ❌ | 무료 | 한국어 미처리 |
| Naver CLOVA Voice | ★★★★★ | ✅ | 기본료 ₩90,000 | **비용 문제로 제외** |
| **Microsoft Edge TTS** | ★★★★☆ | ✅ | **무료** | **최종 채택** |
| OpenAI TTS | ★★★★☆ | ✅ | $0.19 (12,550자) | 유료 |

**최종 선택: Microsoft Edge TTS**
- `edge-tts` Python 패키지, API 키 불필요, 완전 무료
- Microsoft Azure Neural 음성 기반 → 자연스러운 한국어 발음

## 6. 음성 생성 방법

### 방법 A — 슬라이드별 개별 생성 (영상 제작용 권장)

**파일:** `generate_audio_per_slide.py`

```bash
cd "/Users/loveauden/Library/CloudStorage/OneDrive-모빌씨앤씨/전략 사업팀 - BusanBank/제안서_발표"
python3 generate_audio_per_slide.py
```

**처리 내용:**
- 엑셀 A열 슬라이드 No. 기준으로 H열 / G열 스크립트 추출
- 슬라이드별 개별 MP3 생성 (`slide_audio/slide_01.mp3` ~ `slide_59.mp3`)
- 5개씩 병렬 처리로 속도 최적화

**출력:**
```
slide_audio/
├── slide_01.mp3   (슬라이드 1 전용)
├── slide_02.mp3   (슬라이드 2 전용)
└── ... (slide_59.mp3까지)
```

**소요 시간:** 약 2~3분

> 영상 씽크 원리: 슬라이드 No. = PNG 번호 = MP3 번호로 1:1 정확 매칭

---

## 8. 목소리 변경 방법

`generate_audio_per_slide.py` 또는 각 스크립트 상단의 `VOICE` 변수 수정:

```python
VOICE = "ko-KR-HyunsuMultilingualNeural"  # 현재: 남성 (부드러움)
VOICE = "ko-KR-InJoonNeural"              # 남성 (또렷함)
VOICE = "ko-KR-SunHiNeural"               # 여성
```

변경 후 스크립트 재실행 → 영상도 `generate_video.py` 재실행 필요.
